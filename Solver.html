How To Install

  1. Download the ZIP file using the button above.
  2. Right click the ZIP file and press Extract All or Unzip.
  3. Open Chrome and go to:
    chrome://extensions
  4. Turn on Developer Mode in the top right.
  5. Press Load unpacked.
  6. Select the extracted extension folder.
  7. The extension should now appear in Chrome.

Gemini API Key Setup

This extension requires a Gemini API key to work.

  1. Go to the Google AI Studio website:
  2. https://aistudio.google.com/app/apikey
  3. Sign in with your Google account.
  4. Create a new API key.
  5. Copy the API key.
  6. Paste it into the extension settings or popup when prompted.

Important

  • Keep your API key private.
  • Do not share your extracted extension folder publicly.
  • Works on Chromium browsers such as Chrome, Edge, Brave, and Opera.
